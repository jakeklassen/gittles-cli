# gittles-cli

Gittles is a Github stars CLI tool. We will use a local SQLite database and the Drizzle ORM to store data. This is completely CLI driven.

## Auth

The user should sign in via Github.

## Navigation

You are presented with a list of your stars with very basic stats: stars, last updated.

If you press the space bar the larger description is opened. If you press "o" the repo is opened in the browser (the npm package `open` can be used).

## Install

```bash
$ npm install --global gittles-cli
```

```
$ gittles-cli --help

    --name  Your name
```
